# Superstore SQL Analysis

## Project Overview

This project focuses on:

- Data Quality Assessment
- Data Cleaning
- Root Cause Analysis
- Duplicate Detection
- Exploratory Data Analysis (EDA)
- Business Performance Analysis

## Tools Used

- PostgreSQL
- SQL

## Dataset

Global Superstore Dataset

## Key Findings

- 51,290 records analyzed
- No significant missing values detected
- 10,159 date inconsistencies identified
- Root cause: mixed date formats
- Date inconsistencies reduced from 10,159 to 0 after cleaning
- Technology generated the highest profit
- United States generated the highest sales and profit
- Tables generated a loss of 64,084 USD
- High discounts above ~30% caused negative profitability in the Tables subcategory
